\# Sentiment Analysis using Machine Learning



\## Overview

This project performs sentiment analysis on Twitter data using Natural Language Processing (NLP) and Machine Learning techniques. The model classifies tweets into Positive, Negative, and Neutral sentiments.



\## Features

\- Data preprocessing

\- TF-IDF Vectorization

\- Naive Bayes Classifier

\- Logistic Regression Classifier

\- Model evaluation using Accuracy, Precision, Recall, F1-score

\- Confusion Matrix

\- Sentiment Distribution Visualization

\- WordCloud for each sentiment

\- Error Analysis



\## Technologies Used

\- Python

\- Pandas

\- Scikit-learn

\- NLTK

\- Matplotlib

\- Seaborn

\- WordCloud

\- Jupyter Notebook



\## Dataset

Twitter Entity Sentiment Analysis Dataset (Kaggle)



\## Results



| Model | Accuracy |

|--------|-----------|

| Naive Bayes | 71.67% |

| Logistic Regression | 75.55% |



\## Conclusion



Logistic Regression outperformed Naive Bayes and achieved the highest accuracy. This model can be applied to customer feedback analysis, product review classification, and social media sentiment analysis.
