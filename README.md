# 📂 Projects

## 📌 Task 1 – Sentiment Analysis using Machine Learning

### Description

Built a Natural Language Processing (NLP) model to classify Twitter text into **Positive**, **Negative**, and **Neutral** sentiments using TF-IDF Vectorization and Machine Learning algorithms.

### Highlights

* Text Preprocessing
* TF-IDF Vectorization
* Naive Bayes Classification
* Logistic Regression
* Model Evaluation
* Confusion Matrix
* WordCloud Visualization
* Error Analysis

---

## 📌 Task 2 – Autocomplete & Autocorrect Analysis

### Description

Developed an NLP-based autocomplete and autocorrect system using text preprocessing, n-gram language models, Levenshtein Distance, and spell correction techniques.

### Highlights

* Text Preprocessing
* Tokenization
* N-Gram Language Models
* Autocomplete
* Autocorrect
* Spell Checking
* Levenshtein Distance
* Performance Evaluation

---

## 📌 Task 3 – Unveiling the Android App Market (Google Play Store Analysis)

### Description

Performed a comprehensive **Exploratory Data Analysis (EDA)** of the Google Play Store ecosystem using Python. The project involved cleaning real-world app data, analyzing app categories, ratings, installs, pricing trends, and conducting sentiment analysis on user reviews using **TextBlob** to uncover meaningful insights for developers.

### Highlights

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Category Distribution Analysis
* Ratings Analysis
* App Size vs. Installs Analysis
* Free vs. Paid Apps Analysis
* Price Distribution
* Estimated Revenue Analysis
* Sentiment Analysis using TextBlob
* Sentiment by Category
* Interactive Plotly Visualization
* Correlation Analysis

---

## 📌 Task 4 – House Price Prediction using Linear Regression

### Description

Developed an end-to-end **Machine Learning regression model** to predict residential house prices using the **Ames Housing Dataset**. The project includes data preprocessing, feature engineering, exploratory data analysis, correlation analysis, model training, evaluation, and comparison with a regularized regression model.

### Highlights

* Data Cleaning & Preprocessing
* Missing Value Handling
* One-Hot Encoding
* Exploratory Data Analysis (EDA)
* Feature Selection
* Correlation Heatmap
* Linear Regression Model
* Ridge Regression Comparison
* Model Evaluation (MSE, RMSE, R² Score)
* Actual vs Predicted Price Visualization
* Residual Analysis
* Feature Coefficient Analysis

# 🚀 Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/naveenthodendula/OIBSIP.git
```

## 2. Navigate to the Repository

```bash
cd OIBSIP
```

## 3. Install the Required Dependencies

```bash
pip install -r requirements.txt
```

## 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the desired project notebook and run all cells sequentially.
